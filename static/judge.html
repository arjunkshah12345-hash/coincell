Rubric mapping

1. Quality of idea Reese's Law (P.L. 117-171) fixed battery packaging after pediatric deaths. CoinCell addresses the remaining diagnostic gap — distinguishing batteries from coins on X-ray within the 2-hour esophageal emergency window. Stacked coins mimic the double halo sign; this is a named, unsolved clinical failure mode.
2. Implementation Live web app with dual-image upload, probability visualization, Grad-CAM explainability, radial halo chart, clinical protocol engine, and downloadable HTML reports. Responsive dark-mode UI. Deployed on Hugging Face Spaces.
3. Coding excellence Ensemble of OpenCV radial halo profiling + DualViewNet (PyTorch) with battery-weighted loss. Source: GitHub. Tests: python3 tests/smoke_test.py. Architecture: TECHNICAL.md.

Key source files

  • coincell/halo_analyzer.py — radial intensity profiling, Hough fallback
  • coincell/models.py — DualViewNet AP+lateral fusion
  • coincell/inference.py — ensemble + Grad-CAM + protocol
  • coincell/clinical.py — CRITICAL/URGENT/ROUTINE engine
  • tests/smoke_test.py — automated verification

Congressional connection

H.R. 5313 (117th Congress) passed the House 409–2 and became P.L. 117-171 (Reese's Law). CoinCell implements the diagnostic tool that Congress's prevention legislation did not include. Baseline comparison: Rostad et al., Emory SPR 2020 — 81% battery sensitivity, 88% overall accuracy; never deployed clinically.
