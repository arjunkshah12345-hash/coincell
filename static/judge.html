90-second verification

  1. Open the homepage — hero stats show 100% battery sensitivity vs Emory baseline
  2. Press 1 or click Button battery — CRITICAL verdict, X-ray previews load, clinical protocol appears
  3. Press 3 or click Stacked coins — emergency banner despite ambiguous halo (the hard case)
  4. Scroll to Ensemble breakdown — CV + CNN fusion visible
  5. Click Download clinical report — printable HTML with overlays and hotlines
  6. Run tests: python3 tests/smoke_test.py

Rubric mapping

1. Quality of idea Reese's Law (P.L. 117-171) passed 409–2 and mandated child-proof battery packaging after pediatric deaths. Haloscan addresses the remaining diagnostic gap — distinguishing batteries from coins on X-ray within the 2-hour esophageal emergency window. Stacked coins mimic the double halo sign; this is a named, unsolved clinical failure mode.
2. Implementation Production web app: dual-image upload, case library with keyboard shortcuts, probability bars, ensemble breakdown, Grad-CAM explainability, radial halo chart, clinical protocol engine, Reese's Law context, downloadable HTML reports. Responsive dark-mode UI. Weights bundled in repo — runs offline via ./scripts/run.sh.
3. Coding excellence Ensemble of OpenCV radial halo profiling + DualViewNet (PyTorch) with battery-weighted loss (3×). Trained on Kaggle CPU. Source on GitHub. Tests: python3 tests/smoke_test.py. Architecture: TECHNICAL.md.

Congressional connection

H.R. 5313 (117th Congress) passed the House 409–2 and became P.L. 117-171 (Reese's Law). Haloscan implements the diagnostic tool that Congress's prevention legislation did not include. Baseline: Rostad et al., Emory SPR 2020 — 81% battery sensitivity, 88% overall accuracy; never deployed clinically.
